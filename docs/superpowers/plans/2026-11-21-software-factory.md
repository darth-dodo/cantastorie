# Cantastorie Software Factory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port Maya's software factory to cantastorie in full: guardrails, the `factory:*` skills and their supporting skills, OpenSpec planning, GitHub Issues as the work queue (with Linear's history copied), the flywheel, a project board, a post-deploy smoke check and `/health/version`.

**Architecture:** The factory is mostly Claude Code configuration (`.claude/settings.json`, `.claude/skills/`) and docs, ported from `darth-dodo/maya` at `ffbc7bd` with a fixed substitution table. Two small pieces of code are new and test-driven: the Linear migration script and the `/health/version` endpoint. Repo settings (labels, board, branch protection) are applied by an idempotent script, each run with the owner's go-ahead.

**Tech Stack:** Claude Code skills and settings; OpenSpec CLI (`/opt/homebrew/bin/openspec`); `gh` CLI; Python 3.12 + uv + pytest; FastAPI; GitHub Actions; Render.

**Spec:** `docs/superpowers/specs/2026-11-21-software-factory-design.md`

**Source (read-only):** `/Users/abhishek/stuff/ai-adventures/maya` (Maya's `FACTORY.md`, `.claude/`, `.github/pull_request_template.md`, `.github/workflows/smoke.yml`, `scripts/smoke_check.sh`). Never edit the Maya repo.

## Global Constraints

- Every git command targets the worktree by absolute path (`git -C <worktree> …`). Never run git from a shell whose `cd` may have failed.
- One feature branch and one PR per numbered PR below, each cut from `origin/main`. Never commit to `main`.
- No new Python or npm dependencies.
- Conventional Commit messages; no em dashes or en dashes in code comments, docs or commit messages (use commas, colons, parentheses or plain hyphens).
- Never read, print or commit `.env` or any secret; secrets are named, never valued, in docs.
- The owner merges every PR. After PR 1 merges, `gh pr merge` is denied to agents.
- Repo-settings changes (labels, board, branch protection) and the Linear migration run only after the owner says go for that step.
- Security-sensitive Linear issues are never copied to GitHub.
- `settled-architecture` and `docs/adr/` stay authoritative; no settled decision changes in this work.

## Review Focus

- **A ported skill still names a Maya command, path or product term** (`mix`, `Pokémon`, `maya`, `~/maya-factory`, `credo`, `Supabase`): an agent following it runs a command that doesn't exist. Pinned by `tests/factory/test_skills.py` (Task 4).
- **The Linear migration is interrupted and rerun**: a person expects no duplicate GitHub Issues. Pinned by the idempotency test in Task 8.
- **A Linear issue that describes a vulnerability is copied to a public repo**: the person expects it to stay in Linear. Pinned by the security-skip test in Task 8 and the owner's dry-run review in Task 9.
- **`/health/version` leaks configuration**: a person expects only the commit, and an empty string locally. Pinned in Task 10.
- **The smoke check fails a deploy**: the person expects it to report, never block. Pinned by the workflow test in Task 11.

```python
    "Bash(gh pr merge *)",
    "Bash(git push --force *)",
    "Bash(git push -f *)",

    return json.loads(SETTINGS.read_text())["permissions"]


def test_every_guardrail_is_denied() -> None:

    allow = set(_permissions()["allow"])
    for gate in ("Bash(make check *)", "Bash(uv run pytest *)", "Bash(npx vitest run *)"):
        assert gate in allow
```

```python
from __future__ import annotations

import re
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
SKILLS = ROOT / ".claude" / "skills"
FACTORY = ["ask", "plan", "build", "test", "review", "pause", "resume", "cleanup",
           "retro", "improve", "release", "recap", "dashboard"]
FORBIDDEN = re.compile(r"\bmix\b|credo|sobelow|Pok[eé]mon|Supabase|Ecto|Phoenix|maya-j56u|maya-factory|darth-dodo/maya|changelog\.d|Herdr|herdr", re.I)


def _skill(name: str) -> str:
    return (SKILLS / name / "SKILL.md").read_text()


def _frontmatter(text: str) -> dict[str, str]:
    block = text.split("---")[1]
    return dict(line.split(": ", 1) for line in block.strip().splitlines() if ": " in line)


def test_every_factory_skill_exists_with_its_name() -> None:
    for station in FACTORY:
        meta = _frontmatter(_skill(f"factory-{station}"))
        assert meta["name"] == f"factory:{station}"
        assert meta["description"].startswith("Use ")


def test_no_skill_names_a_maya_command_or_product() -> None:
    for path in SKILLS.glob("*/SKILL.md"):
        if path.parent.name.startswith("openspec-"):
            continue  # copied verbatim, product-neutral
        match = FORBIDDEN.search(path.read_text())
        assert match is None, f"{path.parent.name} still says {match.group(0)!r}"


def test_make_targets_named_in_skills_exist() -> None:
    makefile = (ROOT / "Makefile").read_text()
    targets = set(re.findall(r"^([a-z][a-z-]*):", makefile, re.M))
    for path in SKILLS.glob("*/SKILL.md"):
        for target in re.findall(r"`make ([a-z][a-z-]*)", path.read_text()):
            assert target in targets, f"{path.parent.name} names make {target}, which does not exist"
```

```python
"""Copy Linear's Cantastorie issues to GitHub Issues (spec: software factory, Part 2).

Dry run by default. Idempotent: a mapping file records AI-NNN -> issue number as each
issue is created, and a rerun skips anything already mapped. Security-sensitive
issues stay in Linear.
"""

from __future__ import annotations

import argparse
import json
import re
import subprocess
import time
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, Protocol

REPO = "darth-dodo/cantastorie"
PRIORITY = {1: "priority:urgent", 2: "priority:high", 3: "priority:medium", 4: "priority:low"}
PRIORITY_NAME = {1: "Urgent", 2: "High", 3: "Medium", 4: "Low"}
SECURITY = re.compile(
    r"token (exposure|leak)|leaked .*token|account takeover|auth(entication|orization)? bypass|"
    r"unauthenticated|secret|credential|csrf|xss|injection|exploit|vulnerab",
    re.I,
)


class GhRunner(Protocol):
    def __call__(self, args: list[str]) -> str: ...


@dataclass
class MigrationReport:
    to_create: list[str] = field(default_factory=list)
    already_mapped: list[str] = field(default_factory=list)
    kept_in_linear: list[str] = field(default_factory=list)


def _number(identifier: str) -> int:
    return int(identifier.split("-")[1])


def is_security_sensitive(issue: dict[str, Any]) -> bool:
    text = f"{issue.get('title', '')}\n{issue.get('description') or ''}"
    return bool(SECURITY.search(text))


def render_body(issue: dict[str, Any]) -> str:
    lines = [f"Migrated from Linear {issue['identifier']} ({issue['url']})", ""]
    lines.append(issue.get("description") or "(no description)")
    lines += ["", "---", f"Linear status: {issue['status']}"]
    lines.append(f"Linear priority: {PRIORITY_NAME.get(issue.get('priority'), 'None')}")
    if issue.get("assignee"):
        lines.append(f"Assignee: {issue['assignee']}")
    if issue.get("parent"):
        lines.append(f"Epic: {issue['parent']}")
    lines.append(f"Created: {issue['createdAt']}")
    if issue.get("completedAt"):
        lines.append(f"Completed: {issue['completedAt']}")
    if issue.get("duplicateOf"):
        lines.append(f"Duplicate of: {issue['duplicateOf']}")
    return "\n".join(lines)


def _labels(issue: dict[str, Any], epics: set[str]) -> list[str]:
    labels = [PRIORITY[issue["priority"]]] if issue.get("priority") in PRIORITY else []
    if issue["identifier"] in epics:
        labels.append("epic")
    if issue["status"] in ("In Progress", "In Review"):
        labels.append("status:in-progress")
    for name in issue.get("labels", []):
        if name.lower() in ("bug", "feature", "epic") and name.lower() not in labels:
            labels.append(name.lower())
    return labels


def _comments(issue: dict[str, Any]) -> str:
    return "\n\n".join(
        f"**{c['author']}** ({c['createdAt']}):\n\n{c['body']}" for c in issue.get("comments", [])
    )


def migrate(
    export: list[dict[str, Any]],
    mapping_path: Path,
    gh: GhRunner,
    *,
    dry_run: bool,
    pause_s: float = 0.0,
) -> MigrationReport:
    mapping: dict[str, int] = json.loads(mapping_path.read_text()) if mapping_path.exists() else {}
    epics = {i["parent"] for i in export if i.get("parent")}
    report = MigrationReport()
    for issue in sorted(export, key=lambda i: _number(i["identifier"])):
        ident = issue["identifier"]
        if is_security_sensitive(issue):
            report.kept_in_linear.append(ident)
            continue
        if ident in mapping:
            report.already_mapped.append(ident)
            continue
        report.to_create.append(ident)
        if dry_run:
            continue
        args = ["issue", "create", "--repo", REPO, "--title", issue["title"], "--body", render_body(issue)]
        for label in _labels(issue, epics):
            args += ["--label", label]
        url = gh(args).strip()
        number = int(url.rsplit("/", 1)[1])
        mapping[ident] = number
        mapping_path.write_text(json.dumps(mapping, indent=2, sort_keys=True))  # after every issue: resumable
        if issue.get("comments"):
            gh(["issue", "comment", str(number), "--repo", REPO, "--body", _comments(issue)])
        if issue["status"] == "Done":
            gh(["issue", "close", str(number), "--repo", REPO, "--reason", "completed"])
        elif issue["status"] in ("Canceled", "Duplicate"):
            gh(["issue", "close", str(number), "--repo", REPO, "--reason", "not planned"])
        time.sleep(pause_s)  # stay well under GitHub's content-creation rate limit
    return report


def link_epics(export: list[dict[str, Any]], mapping: dict[str, int], gh: GhRunner) -> None:
    """Second pass, once every issue exists: children name their epic as #N, epics list children."""
    by_id = {i["identifier"]: i for i in export}
    children: dict[str, list[str]] = {}
    for issue in export:
        if issue.get("parent") in mapping and issue["identifier"] in mapping:
            children.setdefault(issue["parent"], []).append(issue["identifier"])
    for epic, kids in children.items():
        listing = "\n".join(f"- #{mapping[k]}" for k in sorted(kids, key=_number))
        body = f"{render_body(by_id[epic])}\n\n## Child issues\n{listing}"
        gh(["issue", "edit", str(mapping[epic]), "--repo", REPO, "--body", body])
        for kid in kids:
            kid_body = render_body(by_id[kid]).replace(f"Epic: {epic}", f"Epic: #{mapping[epic]}")
            gh(["issue", "edit", str(mapping[kid]), "--repo", REPO, "--body", kid_body])


def _gh(args: list[str]) -> str:
    return subprocess.run(["gh", *args], check=True, capture_output=True, text=True).stdout


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--export", type=Path, required=True)
    parser.add_argument("--mapping", type=Path, required=True)
    parser.add_argument("--apply", action="store_true", help="create issues (default: dry run)")
    parser.add_argument("--link-epics", action="store_true", help="second pass: fill epic links")
    args = parser.parse_args()
    export = json.loads(args.export.read_text())
    if args.link_epics:
        link_epics(export, json.loads(args.mapping.read_text()), _gh)
        return
    report = migrate(export, args.mapping, _gh, dry_run=not args.apply, pause_s=3.0)
    print(json.dumps(report.__dict__, indent=2))


if __name__ == "__main__":
    main()
```

```python
"""The smoke check reports and never blocks a deploy."""

from __future__ import annotations

from pathlib import Path
from typing import Any

import yaml

ROOT = Path(__file__).resolve().parents[2]


def _workflow() -> dict[str, Any]:
    data: dict[str, Any] = yaml.safe_load((ROOT / ".github/workflows/smoke.yml").read_text())
    return data


def test_runs_hourly_and_after_ci_never_on_push() -> None:
    triggers = _workflow()[True]  # PyYAML reads the "on" key as True
    assert "schedule" in triggers and "workflow_dispatch" in triggers
    assert triggers["workflow_run"]["workflows"] == ["CI"]
    assert "push" not in triggers and "pull_request" not in triggers


def test_the_check_step_can_never_fail_the_job() -> None:
    steps = _workflow()["jobs"]["smoke"]["steps"]
    check = next(s for s in steps if s.get("run") == "scripts/smoke_check.sh")
    assert check["continue-on-error"] is True


def test_the_script_checks_the_three_endpoints() -> None:
    text = (ROOT / "scripts/smoke_check.sh").read_text()
    for path in ("/health", "/play", "/health/version"):
        assert path in text
```
